Why it works

Examples control style. With none, the AI writes the average subject line. With one, it copies that line’s shape, even its first word. With three, it can see what stays the same and what changes, so it copies the pattern and not the sentence.

A format line controls shape. It tells the AI how to lay the answer out so you can use it without retyping: a table for a spreadsheet, labeled pairs for an email tool, counts to catch long lines.

Good examples, bad examples

Use examples that really worked, not ones you merely like. Make them differ from each other on purpose: different openings, different lengths. If all three start with “Your,” so will the output.

You can also show a bad example. “Do not write like this:” followed by a line you hate is a fast way to rule out a whole style.
